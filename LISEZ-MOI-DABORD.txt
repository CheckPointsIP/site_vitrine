🖥️ 3 MODES D'INSTALLATION
═══════════════════════════════════════════════════════════════

MODE 1 : LocalStorage (Aucune installation)
   ✅ Fonctionne immédiatement
   ❌ Données dans le navigateur uniquement

MODE 2 : Serveur Node.js (Recommandé)
   Windows : Double-clic sur start-server.bat
   Mac/Linux : ./start-server.sh
   ✅ Données partagées entre utilisateurs

MODE 3 : Serveur PHP
   → Upload sur hébergement PHP
   ✅ Compatible hébergements classiques (OVH, etc.)
